전투 기획

캐릭터 스탯
HP, AP, 공격력, 방어력, 속도

에너미 스탯
HP, 공격력, 속도

캐릭터의 모든 공격은 방어력 상쇄 없이 트루 데미지

에너미의 모든 공격은 에너미의 공격력 * (100 / (캐릭터의 방어력 + 100))의 데미지로 들어감

속도공식 => 행동수치 : 10000 / UnitSpeed

행동수치가 낮은 유닛이 먼저 행동하고 해당 행동수치만큼 남은 유닛들의 행동수치에서 차감
이후 행동한 유닛의 행동수치를 초기화하고 다시 턴 계산

예시) 스피드가 378인 유닛 A, 스피드가 489인 유닛 B, 스피드가 283인 유닛 C, 스피드가 522인 유닛 D
유닛 A의 행동수치 : 10000 / 378 => 약 26.46
유닛 B의 행동수치 : 10000 / 489 => 약 20.45
유닛 C의 행동수치 : 10000 / 283 => 약 35.34
유닛 D의 행동수치 : 10000 / 522 => 약 19.16

행동수치 순서 (값이 적을수록 속도가 빠름) D > B > A > C

1턴 플레이어 D 행동
모든 플레이어에게서 19.16만큼 값을 뺌
유닛 A : 7.3 / 유닛 B : 1.29 / 유닛 C : 16.18 / 유닛 D : 0 => 초기화 19.16

행동수치 순서 B > A > C > D

2턴 플레이어 B 행동
모든 플레이어에게서 1.29만큼 값을 뺌
유닛 A : 6.01  / 유닛 B : 0 => 초기화 20.45 / 유닛 C : 14.89 / 유닛 D : 17.87

행동수치 순서 A > C > D > B

3턴 플레이어 A 행동
모든 플레이어에게서 6.01만큼 값을 뺌
유닛 A : 0 => 초기화 26.46 / 유닛 B : 14.44 / 유닛 C : 8.88 / 유닛 D : 11.86

행동수치 순서 C > D > B > A

4턴 플레이어 C 행동
모든 플레이어에게서 8.88만큼 값을 뺌
유닛 A : 17.58 / 유닛 B : 5.56 / 유닛 C : 0 => 초기화 35.34 / 유닛 D : 2.98

행동수치 순서 D > B > A > C
